What the labels mean
Applied
The running server reported this value itself, in its startup log or to Steam.
Configured
Read from the server's config file, which the server loaded when it started. The server doesn't report these back.
Restart needed
The config file was changed after the server started. The new value applies after the next restart.
Live
A fact about the running server or its machine, not a setting.
Unknown
Couldn't be determined right now.

The server reads its settings once, when it starts. Every setting here changes only with a restart, except the ban list, which the server updates itself when an admin bans someone in game. "Default" compares a value with the game's Default preset. Hover over a status label to see where its value came from.

Passwords and keys are never sent to this page.
